# Security policy

## Scope

This portfolio is exported as a static website. It has no application server,
database, authentication system, payment flow, or public API. The contact form
opens the visitor's local email client and does not transmit or store form data.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
panickerprathyush20@gmail.com. Do not include secrets or personal data in the
initial report. Allow reasonable time for investigation before public disclosure.

## Maintenance

Production deployments use locked dependencies, immutable GitHub Action commit
references, least-privilege workflow permissions, automated dependency checks,
and a static Content Security Policy.
